# Course tutor avatar trial demo

A fictional, scripted tutoring demo with a 3D avatar created from the reference picture using MetaPerson Creator. The browser can rotate the avatar and plays an idle blink. The optional browser voice reads scripted text but is not lip-synced. There is no live AI tutor or real course material in this demo.

The exported avatar is a MetaPerson free trial/non-commercial asset, subject to Avatar SDK's terms; it is not covered by the Three.js MIT license. Check the applicable license before any commercial or production use. The avatar has a humanoid rig and ARKit-style facial shapes. The optional viseme export was not included.
